# Google Photos Backup & Sync Bot

Локальный Windows-бот и графическое приложение для резервного копирования фото и видео из Google Photos с последующей безопасной очисткой облака.

Идея простая: все найденные медиафайлы сохраняются в локальный архив на диск, а из Google Photos удаляются только те блоки, которые уже подтверждены локальным manifest и старше `DAYS_TO_KEEP_IN_CLOUD`.

---

## Возможности

- 🖥️ **Современный нативный интерфейс (CustomTkinter):** Оформление в стиле Windows 11 Fluent Design (темная/светлая тема), быстрый запуск без зависаний UI благодаря фоновому воркеру `BotRunner`.
- 📊 **Дашборд метрик:** Отображение объема архива, количества файлов, живой счетчик скачиваний и удалений за текущий сеанс.
- ⚙️ **Визуальный конфигуратор настроек:** Выбор папки архива через системный проводник Windows (`Обзор...`), ползунки периодов хранения, динамические бейджи безопасности и защита от случайного удаления.
- 📋 **Инспектор манифеста и экспресс-аудит:** Просмотр состояния `backup_manifest.json`, поиск по датам, фильтрация блоков и запуск аудита целостности без открытия консоли.
- 📜 **Живой журнал логов:** Терминал с цветовой подсветкой уровней (RUN, INFO, WARNING, ERROR), поиском, автоскроллом и фильтрацией.
- 🛡️ **Многоуровневая безопасность:** Режим `DRY_RUN_DELETE` по умолчанию, проверка SHA-256 хешей, подтверждение удаления в DOM Google Photos.

## Быстрый Старт

Самый простой способ для Windows 10/11:

1. Установите Python 3 с официального сайта: https://www.python.org/downloads/windows/
2. При установке Python обязательно включите галочку **`Add python.exe to PATH`**.
3. Скачайте архив проекта и распакуйте его в любую удобную папку.
4. Запустите **`start_bot.bat`** двойным кликом мыши.
5. При запуске появится меню выбора режима:
   ```text
   ========================================
   Select launch mode:
     [1] Graphical Interface (GUI) - Recommended
     [2] Console Mode (CLI)
   ========================================
   Choose mode [1/2] (Default in 10s is GUI: 1):
   ```
   *По умолчанию через 10 секунд откроется графический интерфейс (GUI).*
6. Во вкладке **«Настройки»** укажите целевую папку архива (`DEST_DIR`) через кнопку «Обзор...» и нажмите «Сохранить».
7. Нажмите **«▶ Запустить синхронизацию»** на Дашборде.
8. При первом старте бот откроет окно Chromium: войдите в свой Google-аккаунт вручную (сессия сохранится в `bot_profile` для всех последующих запусков).

`start_bot.bat` сам создает виртуальное окружение `venv`, устанавливает зависимости из `requirements.txt` (включая Playwright и CustomTkinter), ставит браузер Chromium и подготавливает конфигурацию.

## Запуск из командной строки

Если вы предпочитаете запускать компоненты вручную:

**Графический интерфейс:**
```powershell
venv\Scripts\python.exe gui_app.py
```

**Консольный режим (CLI):**
```powershell
venv\Scripts\python.exe google_photos_bot.py
```

**Аналитика и аудит манифеста:**
```powershell
venv\Scripts\python.exe manifest_report.py
venv\Scripts\python.exe manifest_report.py --delete-candidates
venv\Scripts\python.exe manifest_report.py --errors
```

**Запуск тестов:**
```powershell
venv\Scripts\python.exe -m unittest discover -p "test_*.py"
```

## Безопасность Удаления

Удаление из Google Photos выполняется **только если одновременно выполнены условия**:

- Блок старше `DAYS_TO_KEEP_IN_CLOUD`.
- Локальная копия уже скачана.
- Файлы проверены по SHA-256 и записаны в `backup_manifest.json`.
- Для групповых блоков одиночные item-записи корректно покрыты группой.
- `DRY_RUN_DELETE` выключен (`false`), а `ALLOW_CLOUD_DELETE` включен (`true`).
- После клика удаления Google Photos подтвердил исчезновение исходного checkbox из DOM.

Если скачивание было прервано, файл не считается подтвержденным и ни при каких обстоятельствах не будет удален из облака.

## Структура Проекта

- `start_bot.bat` — единый лаунчер и установщик с интерактивным выбором GUI/CLI.
- `gui_app.py` — точка входа графического интерфейса.
- `gui/` — модульный пакет GUI на CustomTkinter:
  - `gui/app.py` — главное окно, навигация, опрос очереди сообщений.
  - `gui/runner.py` — фоновый воркер `BotRunner` и `QueueLogHandler`.
  - `gui/config_manager.py` — менеджер и валидатор конфигурации.
  - `gui/views/dashboard_view.py` — витрина метрик, прогресс и кнопки запуска.
  - `gui/views/settings_view.py` — форма настроек с системным выбором папок.
  - `gui/views/manifest_view.py` — аналитика манифеста и аудит целостности.
  - `gui/views/logs_view.py` — терминал логов с цветной подсветкой.
- `google_photos_bot.py` — ядро браузерной синхронизации (Playwright).
- `manifest_report.py` — аналитика и аудит манифеста без запуска браузера.
- `test_gui.py`, `test_download_retry.py` — модульные тесты воркера, настроек и скачивания.
- `wiki/` — подробная документация архитектуры, компонентов и алгоритмов.
