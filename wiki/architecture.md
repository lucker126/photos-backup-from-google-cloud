# Архитектура

## Общая схема

```
[Пользователь] → [start_bot.bat] → [venv + Playwright] → [Chrome]
                                    ↓
                            [google_photos_bot.py]
                                    ↓
        ┌─────────────────────────────────────────────┐
        ↓                                             ↓
[Google Photos UI]                        [Локальная обработка]
- Навигация по галерее                    - Распаковка ZIP
- Выбор блоков (клик)                     - Дедупликация
- Скачивание (Shift+D)                    - SHA-256 верификация
- Удаление (корзина)                      - Запись в manifest
        ↓                                             ↓
        └─────────────────────┬───────────────────────┘
                              ↓
                    [backup_manifest.json]
                    [app.log]
                    [DEST_DIR/Фото Google YYYY/]
```

## Поток данных

### 1. Инициализация
- `start_bot.bat` создает `venv`, ставит зависимости, запускает `google_photos_bot.py`
- Python читает `config.json` (или создает из дефолта)

### 2. Браузерный цикл
- Playwright запускает Chromium с persistent profile (`PROFILE_DIR`)
- Проверяет авторизацию, ждет ручного входа если нужно
- Начинает цикл обработки блоков (групп фото)

### 3. Обработка блока
Для каждого блока (группа фото по дате или одиночный item):

```
┌─────────────────┐
│ Найти checkbox  │
└────────┬────────┘
         ↓
┌─────────────────┐     ┌─────────────────┐
│ Парсить дату    │────→│ Проверить STOP  │
│ из aria-label   │     │ _AT_DATE        │
└────────┬────────┘     └─────────────────┘
         ↓
┌─────────────────┐
│ Вычислить block │
│ _id             │
└────────┬────────┘
         ↓
┌─────────────────┐     ┌─────────────────┐
│ Проверить в     │────→│ Если verified   │
│ manifest        │     │ и не старый     │
└────────┬────────┘     │ → skip          │
         │              └─────────────────┘
         ↓
┌─────────────────┐
│ Клик по checkbox│ (3 попытки + JS fallback)
└────────┬────────┘
         ↓
┌─────────────────┐     ┌─────────────────┐
│ Скачать (Shift+D)│────→│ Обработать ZIP  │
└────────┬────────┘     └─────────────────┘
         ↓
┌─────────────────┐
│ Верифицировать │
│ SHA-256         │
└────────┬────────┘
         ↓
┌─────────────────┐     ┌─────────────────┐
│ Записать в      │────→│ Если старый →   │
│ manifest        │     │ удалить из облака│
└─────────────────┘     └─────────────────┘
```

### 4. Завершение
- После обработки всех блоков выводится итоговый отчет
- Браузер закрывается

## Компоненты

| Компонент | Файл | Ответственность |
|-----------|------|-----------------|
| Бот | `google_photos_bot.py` | Основная логика, UI-автоматизация |
| Отчеты | `manifest_report.py` | Анализ manifest без запуска браузера |
| Установщик | `start_bot.bat` | Установка зависимостей, первый запуск |
| Конфиг | `config.json` | Настройки пользователя |
| Состояние | `backup_manifest.json` | Результат работы, источник истины |
| Логи | `app.log` | История запусков |

См. [[components]] для детального разбора каждого модуля.
