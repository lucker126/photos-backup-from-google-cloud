# Обзор проекта

## Что это

**Google Photos Backup Bot** — локальный Python-скрипт для Windows, который автоматизирует резервное копирование фотографий и видео из Google Photos на локальный диск с опциональным удалением из облака после подтверждения архивирования.

## Зачем

Google Photos не предоставляет API для массового скачивания и удаления медиафайлов. Единственный "официальный" способ — Google Takeout, но он:
- Требует ручного запуска и ожидания архивации
- Не поддерживает инкрементальные бэкапы
- Не позволяет управлять облачным хранилищем после скачивания

**Решение:** браузерная автоматизация через Playwright — имитация действий пользователя в реальном браузере Chrome.

## Ключевая идея

### Стратегия "горячего и холодного хранения"

1. **Все** новые и старые фото скачиваются на локальный диск
2. Из облака удаляются только файлы старше `DAYS_TO_KEEP_IN_CLOUD` дней (по умолчанию 180)
3. Старые фото остаются в облаке — они доступны в галерее телефона для просмотра

### Безопасность через верификацию

Любой файл удаляется из облака только после того, как его локальная копия:
- Распакована из ZIP или сохранена напрямую
- Проверена по SHA-256 хешу на диске
- Зафиксирована в `backup_manifest.json` с `files_verified=true`

Если скачивание прервано — файл не считается подтвержденным и не удаляется.

## Базовый сценарий использования

1. Запускаете `start_bot.bat`
2. Открывается браузер Chrome с вашим профилем Google
3. Бот скроллит галерею, находит группы фото по дням
4. Для каждой группы: скачивание → верификация → запись в manifest → удаление (если старше порога)
5. В конце выводится отчет: сколько скачано, сколько удалено, периоды дат

## Ограничения подхода

- **Зависимость от UI Google**: если Google изменит интерфейс Photos, селекторы сломаются
- **Скорость**: эмуляция кликов и ожидание анимаций ограничивают throughput
- **Нестабильность**: таймауты скачивания случаются (см. [[known-issues]])

## Текущее состояние

Проект рабочий, но имеет известные проблемы:
- Таймауты при скачивании (`Timeout 120000ms exceeded while waiting for event "download"`)
- Browser crash при скачивании (`Target page, context or browser has been closed`)
- Галерея может не загружать чекбоксы (шаг `wait_for_selector` не находит элементы)

См. [[known-issues]] для деталей и возможных решений.
