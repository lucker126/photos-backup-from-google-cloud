# История проекта

## Истоки

Проект родился из личной потребности: необходимо было резервное копирование фотографий из Google Photos, но единственный способ сделать это программно — через браузер, так как Google не предоставляет публичного API для массовой загрузки и удаления медиа.

Изначально это был простой имитатор кликов (селениум-подобный подход), который работал для базовых задач.

## Эволюция

### Период: начало → функционирующий бот
Скрипт вырос из простого имитатора в полноценную систему с:
- **Playwright** вместо Selenium (стабильность, скорость)
- **Manifest-системой** для отслеживания состояния (SHA-256 верификация файлов)
- **Умной навигацией** по React Virtual DOM (скролл, ожидание элементов)
- **Безопасностью**: dry-run, лимиты удаления, подтверждение хешей
- **Отчетностью**: `manifest_report.py` для анализа без запуска браузера

### Период: повышенная сложность → зрелость
Добавлены механизмы идемпотентности:
- **date coverage** — покрытие одиночных item-записей групповыми блоками
- **каскадное удаление** в manifest
- **восстановление после прерываний** (перезапуск безопасен)

## Проблемы на текущий момент

> "бот" родился от того, что мне нужно было бэкапить фотки из гугл облака, но это возможно только через браузер. вот и сделали имитатор кликов, который работал, но сейчас есть проблемы.

По мере развития UI Google Photos менялся, что сломало часть селекторов и логику. Последние известные проблемы:
- Таймауты скачивания (`Timeout 120000ms exceeded`)
- Crash страницы при скачивании
- Пустая галерея при старте (`wait_for_selector не нашел чекбоксы`)

См. [[known-issues]] для подробного разбора.
