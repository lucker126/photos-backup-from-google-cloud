# Google Photos Backup Bot — Wiki

> Локальный Windows-бот для резервного копирования фото и видео из Google Photos с последующей безопасной очисткой облака через браузерную автоматизацию.

Эта вики предназначена для LLM-агентов и разработчиков: здесь собрана структурированная документация по проекту — от мотивации до деталей реализации.

## Ключевые факты

- **Язык:** Python 3 (sync API)
- **Автоматизация:** Playwright + Chromium (persistent profile)
- **Медиа:** PIL/Pillow для EXIF
- **Хранение состояния:** JSON manifest с SHA-256 верификацией
- **Безопасность:** dry-run по умолчанию, удаление только после подтвержденной локальной копии
- **Платформа:** Windows 10/11
