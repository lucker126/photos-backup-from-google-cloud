# Roadmap и идеи развития

## Краткосрочные (bugfix)

- [ ] **Retry для таймаута скачивания** — сейчас `expect_download(timeout=120s)` без повторных попыток. Добавить 2-3 retry с re-click.
- [ ] **Обновление селекторов** — Google периодически меняет UI. Нужна проверка актуальности `[role="checkbox"]` и fallback на альтернативные селекторы.
- [ ] **AVHD-конвертация** — интегрировать `heif-convert` или `ffmpeg` для автоматической конвертации `.avhd` → `.jpg`.

## Среднесрочные (enhancement)

- [ ] **Асинхронная обработка файлов** — пока скачивается следующий ZIP, текущий уже распаковывается и хешируется (нужен переход на async API Playwright).
- [ ] **Progress bar** — визуальный прогресс в консоли через `tqdm` или `rich`.
- [ ] **Telegram-уведомления** — отправка отчета после завершения (сколько скачано, удалено, ошибок).
- [ ] **Веб-интерфейс** — Flask/FastAPI для просмотра статистики и ручного управления manifest.

## Долгосрочные (strategic)

- [ ] **Поддержка нескольких аккаунтов** — переключение между профилями через конфиг.
- [ ] **Инкрементальный бэкап** — сейчас бот сканирует всю галерею. Идея: запоминать `last_scanned_date` и начинать с неё.
- [ ] **Google Drive интеграция** — загрузка локальных бэкапов в Drive как второй уровень защиты.
- [ ] **Docker-контейнер** — для кроссплатформенности (Linux/Mac через X11 forwarding или headful Wine).

## Идеи от сообщества

- Экспорт в `immich` / `PhotoPrism` — self-hosted альтернативы Google Photos
- Поддержка Yandex Disk / Dropbox как целевого хранилища
- AI-категоризация перед бэкапом (удалять скриншоты, дубликаты, memes)
