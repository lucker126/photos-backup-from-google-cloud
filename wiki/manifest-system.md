# Система состояния (manifest)

`backup_manifest.json` — единственный источник истины о том, что скачано и удалено.

## Зачем manifest

Браузер «не помнит» прошлые запуски. После закрытия страницы Google Photos не знает, какие файлы у вас уже есть локально. Manifest решает это:

- **Идемпотентность** — повторный запуск не скачивает заново
- **Безопасность** — удаление только после верификации
- **Анализ** — `manifest_report.py` работает без браузера

## Ключевые функции

### `load_manifest()`
- Читает JSON
- Мигрирует legacy схемы (v1: list / v2: `blocks` → v3: `items`)
- Удаляет дубликаты по `block_id`
- Возвращает dict, готовый для `run()`

### `save_manifest(manifest)`
- Атомарная запись через temp file + rename (защита от corrupt при crash)
- Сортирует ключи для детерминированного diff в git

### `get_verified_block_ids_from_manifest()`
Возвращает set `block_id`, у которых:
- `files_verified=true`
- Все файлы существуют на диске (`os.path.exists`)
- Все `sha256` совпадают с текущим хешем на диске

Это строгий фильтр — если файл был перемещен/удален вручную, блок «откатывается» к unverified.

## Date coverage

**Проблема:** Один день может существовать как `GROUP: 15 июля 2023 г.` (массовый блок) и несколько `ITEM: IMG_....jpg` (одиночные фото).

**Решение:** после верификации группы все item-записи на ту же дату считаются покрытыми. Они:
- Не скачиваются заново
- Пропускаются в цикле `run()`

**Условие покрытия:**
```python
group_date = parse(entry['date'])
item_date = parse(item_entry['date'])
if group_date == item_date and group_entry['files_verified']:
    covered = True
```

## Каскадное удаление

При `select_and_delete_group()`:
1. Удаляется группа из облака
2. Все item-записи на эту же дату помечаются `deleted_from_cloud=true`
3. Это предотвращает «висячие» item'ы, которые больше не существуют в облаке

## Валидация целостности

При каждом `load_manifest()` проверяется:
- Нет дубликатов `block_id`
- Все обязательные поля присутствуют
- `date` парсится в `datetime`

Невалидные записи логируются как WARNING и пропускаются.
