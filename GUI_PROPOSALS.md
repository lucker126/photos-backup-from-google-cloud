# Концепции и варианты GUI для Google Photos Backup Bot

> Документ содержит предложения по реализации графического интерфейса (GUI) для проекта резервного копирования и синхронизации Google Photos с акцентом на использование в среде **Windows 10/11**, отличный UI/UX, простоту развертывания и безопасность.

---

## 1. Сравнительный обзор вариантов

| Критерий | Вариант 1: Нативный Windows GUI (CustomTkinter) | Вариант 2: Локальный Web Dashboard (FastAPI + Tailwind/Chart.js) | Вариант 3: Премиум Desktop (PyWebView + Edge WebView2) |
|---|---|---|---|
| **Тип приложения** | Классическое нативное окно Windows (`.exe` / `.pyw`) | Локальный веб-дашборд в браузере / PWA (`127.0.0.1`) | Однооконное десктопное приложение (без рамок браузера) |
| **Технологический стек** | Python, `customtkinter`, `threading` | Python, `FastAPI`, `Uvicorn`, WebSockets, Tailwind CSS, Chart.js | Python, `pywebview` (системный Edge WebView2), HTML/Tailwind/Vue |
| **Стиль оформления** | Fluent Design / Windows 11 (темная/светлая тема, скругления) | Современный Web SaaS Dashboard (карточки, интерактивные графики) | Glassmorphism / Acrylic Windows 11 UI с анимациями |
| **Зависимости** | Минимальные (`pip install customtkinter`) | Средние (`fastapi`, `uvicorn`, `websockets`) | Средние (`pywebview`, системный WebView2 уже есть в Windows) |
| **Интеграция с Windows** | Нативные проводники папок, запуск по ярлыку, нет сети | Открытие вкладки в Chrome/Edge, доступ по локалке | Системный трей, Windows Toast-уведомления, нативные диалоги |
| **Потоковые логи** | Текстовый виджет с подсветкой уровней (INFO, WARN, ERR) | WebSocket live-терминал с фильтрами и автоскроллом | Live-консоль + прогресс-бары этапов |
| **Оценка сложности** | **3 из 10 (Низкая / Средняя)** | **5 из 10 (Средняя)** | **6 из 10 (Средняя / Выше средней)** |
| **Сроки прототипа** | 1–2 дня | 2–3 дня | 3–4 дня |

## Вариант 1: Нативный Windows 11 GUI на CustomTkinter

### 💡 Концепция
Легковесное, классическое десктопное приложение для Windows на базе библиотеки `customtkinter`. Она модернизирует стандартный `tkinter`, добавляя поддержку темной/светлой темы Windows 11, плавные скругленные кнопки, карточки параметров и современные поля ввода.

### 🖼️ Структура интерфейса (Мокап)
```
+------------------------------------------------------------------------------------+
|  📷 Google Photos Backup & Sync Bot                         [ — ] [ 口 ] [ X ]     |
+------------------------------------------------------------------------------------+
|  [ 🚀 Управление ]  [ ⚙️ Настройки ]  [ 📊 Манифест и Отчет ]  [ 📜 Журнал логов ]   |
+------------------------------------------------------------------------------------+
|  СТАТУС: ● Бот готов к работе (Сессия активна)                                      |
|                                                                                    |
|  +------------------+  +------------------+  +------------------+  +-------------+ |
|  | Файлов в архиве  |  | Загружено сегодня|  | Удалено из облака|  | Общий объем | |
|  |     14,250       |  |      +128        |  |        12        |  |  84.3 ГБ    | |
|  +------------------+  +------------------+  +------------------+  +-------------+ |
|                                                                                    |
|  Текущий блок: "14 мая 2024" (Осталось дней в облаке: 142)                         |
|  [========================================                  ] 65% (Скачивание ZIP) |
|                                                                                    |
|  [ ▶️ ЗАПУСТИТЬ СИНХРОНИЗАЦИЮ ]    [ ⏸ ПАУЗА ]    [ 🛑 ОСТАНОВИТЬ ]                |
|                                                                                    |
|  +-- Быстрый лог сессии ---------------------------------------------------------+ |
|  | 22:15:01 [INFO] Скачан архив: photos-20240514.zip (45 МБ)                     | |
|  | 22:15:04 [INFO] Распаковано 18 фото, дубликатов: 0, верифицировано: 18         | |
|  | 22:15:06 [INFO] Удаление пропущено: возраст 152 дн. < порога 180 дн.           | |
|  +-------------------------------------------------------------------------------+ |
+------------------------------------------------------------------------------------+
```

### Ключевые возможности
1. **Запуск и контроль в один клик:** Кнопка «Старт» запускает бота в фоновом потоке (`threading.Thread`), основной интерфейс никогда не зависает.
2. **Визуальный конфигуратор `config.json`:**
   - Выбор целевой папки `DEST_DIR` через системный диалог проводника Windows (`Обзор...`).
   - Ползунки для `DAYS_TO_KEEP_IN_CLOUD` (с наглядной подсказкой «Файлы до 18 апреля 2026 будут удалены»).
   - Четкие переключатели для безопасного режима: `DRY_RUN_DELETE` подсвечивается зеленым («Безопасно»), при включении реального удаления появляется предупреждающий бейдж.
3. **Прямой просмотр логов:** Окно с цветовой подсветкой (зеленый для успеха, желтый для предупреждений, красный для ошибок) и кнопкой «Очистить» / «Открыть файл app.log».
4. **Портативность:** Никаких тяжелых node.js или браузерных процессов, потребление RAM всего ~30–50 МБ.

### План реализации
1. **Шаг 1:** Создание модульной структуры `gui/` (модели состояний, поток выполнения бота, перехватчик `logging.Handler`).
2. **Шаг 2:** Разработка экрана управления и дашборда метрик (CustomTkinter).
3. **Шаг 3:** Разработка экрана настроек с валидацией путей и параметров `config.json`.
4. **Шаг 4:** Интеграция с оркестратором `google_photos_bot.py` без изменения его ядра безопасности.
5. **Шаг 5:** Тестирование на Windows и компиляция опционального `.exe` через PyInstaller.

### Оценка для реализации
- **Сложность:** ⭐⭐☆☆☆ (Низкая / Средняя)
- **Риски:** Минимальные. Отсутствуют сетевые конфликты портов и антивирусные блокировки веб-сокетов.

## Вариант 2: Локальный Web Dashboard (FastAPI + Tailwind CSS + Chart.js)

### 💡 Концепция
Локальный легковесный веб-сервис на `FastAPI`, запускаемый на `http://127.0.0.1:8765`. При старте бот автоматически открывает вкладку в любимом браузере (Chrome / Edge) либо запускается в режиме отдельного веб-окна (`msedge.exe --app=http://127.0.0.1:8765`).

### 🖼️ Структура интерфейса (Мокап)
```
+------------------------------------------------------------------------------------+
| 🌐 Google Photos Backup Hub     [● Работает]  Темная тема: [x]    Версия: v1.1.0   |
+------------------------------------------------------------------------------------+
|  (Дашборд)     (История и даты)     (Файлы манифеста)     (Конфигурация)           |
+------------------------------------------------------------------------------------+
|                                                                                    |
|   ┌──────────────────────────┐    ┌────────────────────────────────────────────┐   |
|   │ Хранилище бэкапа         │    │ Распределение архива по годам (Chart.js)   │   |
|   │ Всего: 84.3 ГБ           │    │  [2021] █████████ 12 ГБ                    │   |
|   │ 14,250 фото / 380 видео  │    │  [2022] ███████████████ 24 ГБ              │   |
|   │ Покрыто дат: 890 дней    │    │  [2023] ████████████████████ 31 ГБ         │   |
|   └──────────────────────────┘    │  [2024] ████████ 11 ГБ                     │   |
|                                   └────────────────────────────────────────────┘   |
|                                                                                    |
|   ▶ [ Начать резервное копирование ]   ⏸ [ Пауза ]   Лимит блоков: [ 5 ]          |
|                                                                                    |
|   Таблица манифеста (Поиск по дате: [ 2024-05    ])                                |
|   ┌────────────┬─────────────┬───────────┬──────────────┬──────────────────────┐   |
|   │ Дата блока │ Тип         │ Файлов    │ Статус       │ Действие             │   |
|   ├────────────┼─────────────┼───────────┼──────────────┼──────────────────────┤   |
|   │ 2024-05-14 │ group       │ 18 файлов │ ✅ В архиве  │ [Показать файлы]     │   |
|   │ 2024-05-13 │ group       │ 42 файла  │ 🗑️ Удалено   │ [Лог удаления]       │   |
|   │ 2024-05-10 │ item        │ 1 файл    │ 🛡️ Покрыто   │ [block_id]           │   |
|   └────────────┴─────────────┴───────────┴──────────────┴──────────────────────┘   |
|                                                                                    |
|   Терминал событий (WebSocket Live Stream):                                        |
|   > [22:15:10] Playwright Chromium подключен к постоянному профилю bot_profile      |
|   > [22:15:12] Обнаружено 4 новых блока фото в области видимости...                |
+------------------------------------------------------------------------------------+
```

### Ключевые возможности
1. **Глубокая аналитика и инфографика:** Интерактивные диаграммы объема по годам, процент удаленных файлов, временная шкала бэкапа.
2. **Полноценный проводник по манифесту:** Поиск, фильтрация по годам, детальный просмотр файлов каждого блока и их SHA-256 хешей прямо из браузера.
3. **WebSocket Live-консоль:** Мгновенный вывод логов и прогресса без перезагрузки страниц.
4. **Красивый современный UI:** Tailwind CSS, карточки статистики, плавная темная тема, адаптивность.

### План реализации
1. **Шаг 1:** Создание REST API на `FastAPI` для отдачи статистики, чтения/записи `config.json` и вызовов функций аудита из `manifest_report.py`.
2. **Шаг 2:** Реализация WebSocket эндпоинта для передачи логов бота в браузер в реальном времени.
3. **Шаг 3:** Разработка фронтенда на чистом HTML5 + Tailwind CSS + Alpine.js (без сборщиков node.js для максимальной простоты).
4. **Шаг 4:** Добавление графиков Chart.js (годовые объемы, динамика скачиваний).
5. **Шаг 5:** Интеграция запуска в `start_bot.bat` с автоматическим открытием браузера.

### Оценка для реализации
- **Сложность:** ⭐⭐⭐☆☆ (Средняя)
- **Риски:** Необходимость открывать локальный сетевой порт (может вызывать запрос брандмауэра Windows при первом старте).

## Вариант 3: Премиальное Windows-приложение (PyWebView + Edge WebView2)

### 💡 Концепция
Современное настольное приложение, объединяющее веб-технологии и системную интеграцию Windows через компонент **Microsoft Edge WebView2** (встроен во все версии Windows 10 и 11). 
В отличие от Electron, здесь **не тащится 200 МБ Chromium**, а используется системный движок, благодаря чему вес дистрибутива остается в пределах 5–10 МБ.

### 🖼️ Структура интерфейса (Мокап)
```
+------------------------------------------------------------------------------------+
| 📷 Google Photos Sync Hub   [Статус: Готов]                      —  口  ✕ (Win-title)
+------------------------------------------------------------------------------------+
| 📁 Главная        │  Добро пожаловать, Сергей!                                     |
| ⚙️ Настройки      │  Резервная копия синхронизирована с диском D:\                  |
| 📋 Манифест       │                                                                |
| 📈 Аналитика      │  +----------------------------------------------------------+  |
| 🔕 В трей         │  │ 🛡️ Защита данных: DRY RUN включен (Тестовый прогон)      │  |
|                   │  +----------------------------------------------------------+  |
|                   │                                                                |
|                   │  ПАРАМЕТРЫ ЗАПУСКА:                                            |
|                   │  Папка сохранения: [ D:\Фото Google             ] [Обзор...]   |
|                   │  Хранить в облаке: [ 180 дней                   ] [ — | + ]    |
|                   │  Лимит за запуск:  [ 5 блоков                   ]              |
|                   │                                                                |
|                   │  [  🚀 НАЧАТЬ СИНХРОНИЗАЦИЮ  ]     [ 🧪 ТЕСТОВЫЙ ПРОГОН ]       |
|                   │                                                                |
|                   │  АКТИВНЫЙ ПРОЦЕСС:                                             |
|                   │  ▶ Скачивание архива: 2024-05-14 (18 файлов, 42 МБ)            |
|                   │  [███████████████████████████████████░░░░░░░░░] 78%            |
|                   │                                                                |
|                   │  Уведомления Windows: [Включены]                               |
+------------------------------------------------------------------------------------+
```

### Ключевые возможности
1. **Визуальный уровень Windows 11:** Плавные тени, закругления, акриловый блюр (Mica/Acrylic), кастомный заголовок окна.
2. **Интеграция с системным треем:** При длительном бэкапе окно можно свернуть в область уведомлений Windows (возле часов), бот продолжит фоновую работу.
3. **Нативные Toast-уведомления Windows:** Всплывающее системное сообщение по окончании: «Бэкап завершен: скачано 150 фото, облако очищено на 1.2 ГБ».
4. **Двусторонний мост Python <-> JS:** Нажатие на кнопку в интерфейсе напрямую вызывает Python-функцию без HTTP-серверов.

### План реализации
1. **Шаг 1:** Каркас приложения на `pywebview` с привязкой системного API Windows.
2. **Шаг 2:** Создание SPA-интерфейса (Tailwind CSS + красивые UI-компоненты).
3. **Шаг 3:** Реализация фонового воркера бэкапа и обработчика событий для обновления прогресс-баров.
4. **Шаг 4:** Добавление сворачивания в системный трей Windows (`pystray`).
5. **Шаг 5:** Интеграция нативных уведомлений (`win10toast` / PowerShell notification).

### Оценка для реализации
- **Сложность:** ⭐⭐⭐⭐☆ (Средняя / Выше средней)
- **Риски:** Требует тщательной отладки взаимодействия потоков Python и событий WebView2.

## 3. Рекомендация архитектора

Если оценивать с точки зрения **баланса между надежностью, скоростью реализации и отличным Windows UX**:

1. **Рекомендуемый выбор №1: Вариант 1 (CustomTkinter)**
   - *Почему:* Это нативный однопроцессный десктопный инструмент. Он не требует поднятия веб-портов, мгновенно стартует, на 100% совместим с любым Windows без проблем с брандмауэром или блокировками портов, и пишется полностью на чистом Python за 1–2 дня.
   - *Для кого:* Идеально, если нужна надежная рабочая лошадка с красивым темным оформлением Windows 11, выбором папок по кнопке «Обзор» и выводом логов.

2. **Рекомендуемый выбор №2: Вариант 2 (Web Dashboard на FastAPI)**
   - *Почему:* Если хочется не просто кнопку запуска, а интерактивный дашборд с графиками по годам, фильтрами по манифесту и подробной аналитикой.
   - *Для кого:* Если хочется видеть красивую веб-панель управления с аналитикой архива.
